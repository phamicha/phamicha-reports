Data & offline updates

Updating this report and publishing on GitHub
  1. Open this HTML in Chrome, Edge, Firefox or Safari. Search, filters, sorting and exports work offline. Source links require Internet.
  2. Import JSON replaces all three datasets; it does not merge them. Keep older entries that remain relevant in the updated data.
  3. After importing, download the full HTML to keep your changes. Closing the tab without downloading discards session changes.
  4. To update GitHub: rename the downloaded file index.html, open the repository, choose Add file → Upload files, replace index.html and commit. The public link stays the same.
  5. One-time Pages setup: Settings → Pages → Deploy from a branch → main → /(root) → Save.
  6. GitHub Pages publishes changed files; it does not research new opportunities. Weekly research and publishing require their own configured workflow.

English is the default. EN/VN switches the interface and translated report descriptions; proper names and original source wording may be retained. Translation does not reverify the underlying facts.
